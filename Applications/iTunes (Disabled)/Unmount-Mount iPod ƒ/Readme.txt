Mount and Unmount iPod 1.2This script will unmount and remount an iPod without requiring the user to physically disconnect it. This is useful for folks who need iTunes to update Smart Playlist or Play Count info, which iTunes will do only on initial connect.Instructions for use: OS 9: There is not an OS 9 version of this script; the problem occurs only in iTunes 3, which is not OS 9 compatible.OSX: Place the script in the "Scripts" folder in "Tunes" in "Library" in "Home". In some cases you might need to create a "Scripts" folder.To run the Script: Make sure your iPod is plugged in to your computer. Run the script and... wait. Compatability: OS X : It's been tested in OS 10.2, with iTunes 3 and an iPod running FIrmware 1.2.1History:1.2 - Thanks to a mod added by Dirk Bewies, the script now works with iPods who have spaces and/or special characters in thier names.1.1 - script will now work if user has audio CD mounted.
