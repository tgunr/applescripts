Import Selected iPod Playlist to iTunesThis script will copy the selected files on an iPod to your iTunes Library in Artist:Album:file.mp3 format, import the files to iTunes, and display them in a playlist called "Imports from iPod".Instructions for use: OSX: Use the Install script to install, or: Place the script in the "Scripts" folder in "iTunes" in "Library" in "Home." In some cases you might need to create a "Scripts" folder. You must have the iPod tracks selected in the main browser window of iTunes for the script to run.Compatability: It's been tested in OSX 10.2.5 It requires iTunes 3 or 4. You should probably have your iPod set to be updated manually.Known Issues: The script works by using the UNIX shell to find mp3/m4a files whose size in bytes matches the size i bytes of the files as itunes reports them. This means that there is a possibiltiy that the script might copy the wrong file - since there is a rmeote possibility that there are two files on the iPod with the same exact size in bytes. I've been using it and it hasn't yet done this, but you should know the possibility exists. Check the playlist the script makes for you to be srue you've copied the correct files.History:v1.2 : Fixed a bug that was causing and EOF error in the UNIX shell when users' iPods had names which included non alphanumeric characters.v1.1 : Updated to support iTunes 4 and download  m4a (AAC) files.
