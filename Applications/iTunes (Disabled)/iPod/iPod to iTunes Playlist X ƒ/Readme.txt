Add iPod Contents as PlaylistThis script is takes a little work on the user's part to set up, but once it's set up, the results are powerful. I wrote it to add the songs from an iPod to the iTunes Library and to a playlist called "*iPod Control". Why? Because Apple, so concerned about people "stealing" music, wrote routines into iTunes that keep people from burning CDs straight from an iPod or from adding the iPod's songs to the iTunes Library. As a person whose interest is less in theivery and more in not having two copies of every file, I wanted to be able to add the files from the iPod to the iTunes Library whic would incread my storage capacity by 5GB and allow me to play songs from the iTunes Library and the iPod's Library in a shuffle together, or to create playlists from both sources.Instructions for use: OS 9: place the script in the "Scripts" folder in the iTunes folder in "Documents." Drag the file called "File Visibility" to your System Folder. A dialog box will ask you if you want to add the file to "Scripting Additions". You do. Once it does this, restart your computer. Your computer is ready to use the script. Select it from the Scripts menu in iTunes and wait a few minutes.OSX: Place the script in the folder "user:Library:iTunes:Scripts". In some cases you may need to create a "Scripts" folder.What about all these files in my Library when I eject my iPod?-Good question. Simply run the script again and it will purge the iPod tracks.Compatability: OS 9: It's been tested in OS 9.2.3 with an iPod running Firmware 1.2. It requires iTunes 2.0.3OS X : It's been tested in OS 10.2, with iTunes 3 and an iPod running FIrmware 1.2
