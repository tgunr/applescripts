This is an example of the new abilities of QuickTime 5.0 to control the display of content. The movie embedded below is a single-frame movie with an assigned HREF targeting a movie located in the same folder as the link movie.

The target movie has its auto present property set to true and its presentation size property set to screen. It also has its quit when done property set to true.

The HREF for the embedded movie targets the QuickTime Player application. When the embedded movie is clicked, it will launch the QuickTime Player, play the movie full screen, and quit the QuickTime Player when the movie has finished playing.
