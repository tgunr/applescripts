QuickTime Scripts for Mac OS XCONTENTS:¥ The QT Applets-Droplets folder contains dozens of AppleScript applet and droplet automation tools. See the Read Me file for an explanation of each.¥ The QuickTime Player Scripts folder contains over 100 AppleScript scripts for the QuickTime Player application. See the Read Me file for an explanation of each. These scripts are designed to be launched from the Script Menu which is in the AppleScript folder in the Applications folder on your startup drive.¥ The Script Templates folder contains script templates to aid you in creating your own scripts. Replace the line: (-- SCRIPT PROCESSING STATEMENTS GO HERE) in each template with your AppleScript commands.The Example Files folder contains example files of some of the new features of QuickTime 5.0.2 scripting and some files to be used for testing the various droplets and applets.REQUIREMENTS:¥ QuickTime 6.3¥ Mac OS X 10.2+¥ Script Menu - A free utility which provides a convienient means for launching compiled scripts from within any application.INSTALLATION:Locate the Script Menu application in the AppleScript folder in the Applications folder on your startup disk. Double-click the application. The Script Menu icon will now appear in the Menu Bar at the top right of your screen. Select the script icon to access the menu. To remove the Script menu, hold down the Command key, click on the Script Menu in the menu bar and drag the icon off the menu bar.Select "Open Scripts Folder" from the Script Menu. Place the QuickTime Player Scripts folder in the Scripts folder. These scripts will now be available from the Script Menu.Copyright ©2003 Apple Computer, Inc.  All rights reserved.
