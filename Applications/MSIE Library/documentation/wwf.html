Intro - "Commands" - Special notes


Working with "Formularios"
"Formularios" is a script object into "MSIE Library". So, if you want use its commands, you must first load the library, and then "tell Formularios" to do anything:
I.e:

set LoadedLibrary to load script alias...
tell Formularios of LoadedLibrary
    -- do some stuff with forms
end tell

It offers support for text fields, textareas, hidden fields, checkboxes, radio buttons, input buttons, select fields and lists.
Now, let's see the "commands" of "Formularios":

description: return extensive info about all forms of the front window
syntax: listforms()
examples:

EXAMPLE 2: various tests (using "example.html")
tell Formularios of LoadedLibrary
    set allinfo to (listforms())

    -- tests the action of first form
    set theaction to faction of first item of allinfo
    -- returns "mailto:someone@somewhere.com"

    -- tests if the checkbox is checked or not
    set theCheckBox to (fElements's item 2 of allinfo's item 1)
    set isChecked to eChecked of theCheckBox
    -- returns true or false

    -- tests the current selection of the pop-up menu
    set PopMenuElements to (fElements's item 3 of allinfo's item 1)
    set PopMenuOptions to eOptions of PopMenuElements
    repeat with i from 1 to count items of PopMenuOptions
        set popnum to PopMenuOptions's item i
        if oSelected of popnum then
            set currentSelection to oText of popnum
            exit repeat
        end if
    end repeat
    currentSelection
    -- returns the current selection, i. e., "genial"
end tell

setvalue
description: set the value of any element of any form (pre-established)
syntax: setvalue()
examples:
EXAMPLE 1: fill the field "Your name:" (using "example.html")
tell Formularios of LoadedLibrary
    -- tell it which element of wich form is the focus of "setvalue()"
    set FormID to 0 -- or its name: "SampleForm"
    set FormElement to 0 -- or its name: "TextField"
    (*
if you're calling elements by its "ID" (ordinal pos.),
you must start numbering at number 0.
So, the second element of a form is the number 1
*)
    -- Finally, specify the value you wish to apply
    set ElementValue to "John Wayne"
    (*
These three "variables" (FormID, FormElement & ElementValue
are the only way to config "setvalue()", and are not optional
*)
    -- And apply it:
    setvalue()
end tell

EXAMPLE 2: fill the entire form (using "example.html")
tell Formularios of LoadedLibrary
    -- Establish the form to fill
    set FormID to "SampleForm"
    -- Establish all the elements we wish fill, as a list
    set FormElement to {0,1,2,3,4}
    -- And its correlative values
    set ElementValue to {"John Wayne", true, 1,true, 0}
    setvalue()
end tell

EXAMPLE 3: fill two forms at the same page
tell Formularios of LoadedLibrary
    -- ID of first form
    set FormID to 0
    set FormElement to {0,1,2}
    set ElementValue to {true, false, "I like football"}
    -- Fill it
    setvalue()
    (*
Now, the second form, overriding the previous values,
because they're remembered by "Formularios"
*)
    set FormID to "AboutUser"
    set FormElement to {"Name",8}
    set ElementValue to {"John Wayne",3}
    setvalue()
end tell

submit
description: submits any form
syntax: submit()
example:
tell Formularios of LoadedLibrary
    -- what form do you want submit?
    set FormID to "SampleForm"
    submit()
end tell

reset
description: reset any form
syntax: reset()
example:
tell Formularios of LoadedLibrary
    -- what form do you want reset?
    set FormID to "SampleForm"
    reset()
end tell

activate
description: activate or deactivate an element in a form
syntax: activate true/false
example:
tell Formularios of LoadedLibrary
    set FormID to "SampleForm"
    set FormElement to 0
    activate true
end tell

select
description: select the text of any text field o textarea in a form
syntax: select
example:
tell Formularios of LoadedLibrary
    set FormID to "SampleForm"
    set FormElement to "Name"
    select
end tell
