Intro
MSIE Library is a little applescript library for Microsoft Internet Explorer, and it provides some "commands" to extend its dictionary's power. It's a little bridge between javascript and applescript and gives to the applescripter-non-javascripter full control over the window object, all elements of forms and some of the typical features working with the browser, such as color, history, dialogs or navigation.
MSIE Library works with IE's versions 4.5 & 5. Not tested in earlier versions nor OS X.

Step 1
MSIE Library is a library, not a scripting addition. So, to invoke it, you must "load" it.
I.e:

set msie_library to alias "YourDisk:..." -- path to "MSIE Library"
set LoadedLibrary to load script msie_library

tell LoadedLibrary
    -- do some stuff
end tell

You can open the "MSIE Library"'s dictionary by choosing "Open dictionary" in your script editor and selecting this library.
It's a simulated dictionary, so you can't, "tell app "MSIE Library" to do some stuff". But, when loaded, it works like a real app...
In order to get access to web page forms, you must “tell Formularios”, a script object embedded into “MSIE Library”.
I.e:

tell Formularios of LoadedLibrary
    -- do some stuff with forms
end tell
