allinfo:boolean (with/without)
without allinfo: returns info about (page title, page url, base url, charset, length's code & forms)
with allinfo: returns, too, (every image url, every embeded object -sounds, movies...-)

aboutmimetype
description: returns info about the specified mimetype/s
syntax: aboutmimetype(parameter)
parameter:string "all" > returns info about every mime type
integer > returns info about mime type... (first mime type is 0)
list of integer > returns info about mime types... (i.e. {0,12,140})
example:
aboutmimetype(25)
-- returns the following record:
{
    MTSuffixes:"mp3,mpeg,mpg,m1s,m1a,mp2,mpm,mpa",
    MTType:"audio/x-mpeg",
    MTDescription:"MPEG audio file",
    PluginEnabled:true,
    PluginName:"QuickTime Plug-in 5.0.2"
}

aboutimage
description: returns info about the specified image
syntax: aboutimage(parameter)
parameter:string "all" > returns info about every image
integer > returns info about image... (first image is 0)
list of integer > returns info about images... (i.e. {0,8,13})
example:
aboutimage(25)
-- returns the following record:
{
    name:"image1",
    src:"http://images.src.com/logotype.gif",
    width:50,
    height:18,
    complete:true,
    border:1,
    vspace:0,
    hspace:0
}
-- "complete" tells us if the image is fully loaded or not

modifyimage
description: modifies some attribute/s of some image/s
syntax: modifyimage(ID,attrib,value)
ID:string ("all"), integer or list of integer > first image is 0
attrib:the attribute to modify, as returned from "aboutimage" > i.e., "border" / {"border", "width"}
value:the value to set up > i.e., 12 / {12,"nameofimage"}
example:
EXAMPLE 1: modify border of first image
modifyimage(0,"border",14)

EXAMPLE 2: modify name & border of images 1 thru 4
modifyimage({0,1,2,3},{"name","border"},{"newname",14})

EXAMPLE 3: reload images not fully loaded
set allimages to (aboutimage("all"))
repeat with i from 1 to count allimages
    set thesrc to src of (allimages's item i)
    modifyimage(i -1,"src",thesrc)
end repeat

openwindow
description: makes a window with. optionally, specified features, and writes some text to it
syntax: openwindow() / openwindow given data:{URL,TITLE,FEATURES,DATA}
URL:
string, the url to open. "" will open a blank window.
TITLE:string/html formatted
FEATURES:string containing:
toolbar (yes/not) > standard navigation toolbar
location (yes/not) > location entry field
directories (yes/not) > standard navigator directory
status (yes/not) > status bar at the bottom of the window
menubar (yes/not) > menu at the window's top
scrollbars (yes/not) > horizontal & vertical scrollbars
resizable (yes/not) > allows the user resize the window
width (integer) > width of the window, in pixels
height (integer) > height of the window, " "
left (integer) > distance from left, " "
top (integer) > distance from top, " "
The syntax would be "toolbar=no,location=yes,width=800,height=600"
DATA:string/html formatted, "" won't write nothing.
example:
EXAMPLE 1: open a new window with some text
openwindow given data:{"", "Hello", "width=400,height=300", "This is a sample<br><font color=FF0000>This is a RED sample<br><font size=6>This is a BIG RED sample"}
-- opens a window with the given features and data

EXAMPLE 2: open Apple's iTools site in a new window
openwindow given data:{"http://homepage.mac.com/", "", "width=800,height=600,location=yes,resizable=yes,scrollbars=yes", ""}

sendcookie
description: stores a cookie, by specifying name, value, and expiration date
syntax: sendcookie(name,value,expirationdate)
name:
string, the name
value:the value
expirationdate:string or list of integer
string: "December 25, 2002", optionally "December 25, 2002 13:58:00"
"" will set up expiration date to current session
list of integer: {YYYY,MM,DD} optionally {YYYY,MM,DD,hh,mm.ss}
* NOTES: "expirationdate" is converted to GMT, so, if you are in, i.e., GMT +1, you must sum 1 hour to the "expirationdate". I.e., if you live in GMT+1, {2002,12,25} will stablish "December 24, 2002 23:00:00 GMT" ("December 25, 2002 00:00:00" - 1 hour).
The "server"'s cookie is the server of the current page. If local, "localhost".
"Protected" status is always false.
"Status" is always enabled/active.
A cookie from the same server and with the same name, overrides the previous one.
If expiration date is a past date (i.e., 1995), it won't be displayed because it expired!!
If you send a cookie from the same server with the same name of one existing cookie, using a past expiration date, you'll delete it.
example:
sendcookie("MyOwnCookie","none special","")
-- returns the cookie.
 "MyOwnCookie=none special;expires=NaN"
-- "NaN" is a java specification: "Not a Number". So, current session.
