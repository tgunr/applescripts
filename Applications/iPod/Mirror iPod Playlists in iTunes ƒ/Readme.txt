Mirror iPod Playlists in iTunesThis script will mirror either the selected playlist or every playlist on an iPod in iTunes provided that the same tracks are in iTunes that are on the iPod. Instructions for use: OSX: Use the Install script to install, or: Place the script in the "Scripts" folder in "iTunes" in "Library" in "Home." In some cases you might need to create a "Scripts" folder. If you want to mirror a single playlist, ou must have the iPod playlist selected in the main browser window of iTunes for the script to run.NOTE: This script does NOT copy songs from the iPod to iTunes. It mirrors playlists. That is all.Compatability: It's been tested in OSX 10.2.5 It requires iTunes 3 or 4. You should probably have your iPod set to be updated manually.
