Rip to iPod v1.0AppleScript for iTunes (OS 9 and OS X)Find more free AppleScriptsand info on writing your ownat Doug's AppleScriptshttp://www.malcolmadams.com/itunes/Imports the enabled (check-marked) CD tracks to iPod via iTunes using your choice of encoder (your Preferences-set encoder is restored afterwards), then removes the tracks from iTunes library and deletes the files from your hard drive.How to use:Put this script in your iTunes Scripts folder. This is located in home > Library > iTunes. If there is no Scripts folder there, create one and put the script in it. It will then appear in iTunes' Scripts Menu, where you can select it by clicking on its name. (It is an AppleScript application–"applet"– and can run from anywhere on your computer, but runs more conveniently from iTunes Scripts Menu.)Before using, make sure iPod is not set to automatically update: select iPod in the iTunes Source pane, click the iPod Options button, and select "Manually manage songs and playlists."Insert a CD, make sure iPod is mounted, and run the script. Select "New Encoder" from the first screen to select a different encoder if you wish. The enabled CD tracks will be imported and sent to the iPod. However, tracks will be removed from iTunes and files deleted from your Hard Drive.Issues:Choosing Encoders - When you select a new encoder–by clicking on "New Encoder" on the main screen–the most recent settings for that encoder will be used. These can be set in iTunes Importing Preferences.International Characters - There is a pesky problem of iTunes sometimes not recognizing international characters when converting from CD (this is true whether converting via AppleScript or not). For these tracks, sorry to say, you will have to convert "by hand" (drag to library).iPod Capacity - The script checks to see if you have a reasonable amount of room left on the iPod before ripping each track. If it appears there is not enough room, the script will alert you and cancel. This will be improved upon in future versions.OS 9 - runs fine using iTunes 2.0.4 in OS 9, with one difference: files are moved to the Trash but the Trash is not emptied."Finished" Chime - The "finished" chime will sound after each track is imported.
